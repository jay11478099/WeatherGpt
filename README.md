# WeatherGPT

Conversational AI weather application for forecasting, alerts, and climate information.

## Quick setup

Read **[SETUP_GUIDE.md](SETUP_GUIDE.md)** for complete installation instructions.

Project folders:

- `flutter_app/` - Flutter application
- `xampp_backend/` - PHP/MySQL backend and admin dashboard
- `docs/` - project presentation guide and documentation

Main technologies: Flutter, Dart, PHP, MySQL, XAMPP, Ollama, and Weather API.
